Notes are for things that stay useful and get updated over time, unlike blog posts which are dated.
Each note is a Markdown file in the `_notes` folder.

| I want to…                 | Edit this                          |
|----------------------------|------------------------------------|
| change name, links, menu   | `_config.yml`                      |
| write a blog post          | new file in `_posts/`              |
| add a note                 | new file in `_notes/`              |
| add a publication          | `_data/publications.yml`           |
| add a news item            | `_data/news.yml`                   |
| change the look            | `assets/css/style.css`             |

A minimal note looks like this:

```markdown
---
title: Reading list on uncertainty
description: Papers I recommend to new students.
updated: 2026-10-10
---

- Kendall & Gal, 2017. What uncertainties do we need…
```
